# PeakSoft Interns Hub

Welcome to the team! This directory is your centralized location for documentation, roadmaps, and implementation journals.

## 📂 Directory Structure

- **Common Documentation**: Located in the root of `interns/`.
- **[Meriem (Track A)](./meriem/)**: Security Intelligence (MQTT, AI, Threat UI).
- **[Farah (Track B)](./farah/)**: Governance & Reliability (Modbus, Compliance, Facility Sync).

## 🚀 Getting Started

1.  Review the **[Intern_Guide.md](./Intern_Guide.md)** for environment setup and coding standards.
2.  Go to your specific folder (`meriem/` or `farah/`) and check your tasks in `Meriem_Tasks.md` or `Farah_Tasks.md`.
3.  Use your **`Implementation_Journal.md`** to document your progress, challenges, and technical decisions.

## 📜 Key Common Docs

- **[Project overview.md](./Project%20overview.md)**: High-level platform architecture.
- **[Concepts_and_Implementation.md](./Concepts_and_Implementation.md)**: Main technical journal of the project.
- **[Backend_Architecture_Design.md](./Backend_Architecture_Design.md)**: DDD and Repository pattern guide.
